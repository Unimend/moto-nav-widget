# MOTO NAV 桌面地图原型

当前 `1.3.2` 是面向 Android 的 Nothing 风格 `3×3` 离线 OpenStreetMap 地图与高德导航原型。组件显示道路、建筑、水系、地名和真实路线；导航时持续更新位置、剩余距离、下一转向和进度，并支持航向朝上、偏航限频重算、动态离线场景、最近目的地与家/公司快捷入口。Doto 用于英文和数字，Zpix 用于中文。

视觉与信息架构参考 [MOTO GPS · Waveshare Edition](https://github.com/mx3353672833-debug/moto-gps-waveshare)，当前项目未复制其 iOS、ESP32 或 LVGL 源码。后续若复用上游代码，需遵守 PolyForm Noncommercial 1.0.0、NOTICE 和第三方许可。

## 构建

```sh
sh build.sh
adb install -r build/moto-nav-widget.apk
```

安装后先打开应用载入当前位置，再将 `3×3`“MOTO 导航组件”添加到桌面。旧的 `3×1` 实例需要删除后重新添加。

真实场景按钮只在用户主动操作后读取一次位置。杭州主城区优先使用随应用提供的离线矢量数据库，不发送当前位置；离线包无覆盖时才通过 OpenStreetMap 标准小范围地图接口载入道路和建筑轮廓。在线请求最长等待约 18 秒，重复点击不会产生排队任务；结果仅缓存在本机，不由本项目服务器收集。地图数据 © OpenStreetMap contributors，ODbL。

离线包覆盖 `119.95–120.35E / 30.10–30.40N`，使用 WGS84 坐标、SQLite R-tree 和简化后的真实 OSM 几何。生成脚本位于 `tools/build_hangzhou_map.py`；原始浙江 PBF、临时工具与本地生成物不会提交到 Git。

离线包 v2 同时保存道路、建筑、水域/绿地/用地、河流/铁路和道路名称。组件围绕当前位置加载约 `2.6×2.6 km` 的场景，并对名称做去重与碰撞避让。配置页可在场景内拖动浏览，双击回到真实位置。

高德 Web 服务 Key 只保存在应用私有 `SharedPreferences`，不写入源码或仓库。地点名搜索优先在当前 GPS 周围 15 km 内按距离返回最多 5 个候选项，无结果时才回退杭州全市文本搜索。路线坐标在 GCJ-02 与 WGS84 之间转换后绘制到 OSM 底图。

路线使用高德路径规划 2.0，支持驾车默认推荐、骑行和步行三种方式。导航地图优先跟随 GPS 行驶航向，低速时跟随手机旋转矢量传感器；地图几何旋转时，道路与建筑名称保持屏幕正向。角度只在发生变化时做低帧率插值，停止转动后停止额外重绘。当前位置使用小圆点与独立朝向箭头组合，定位呼吸环、转向图标和底部路线进度均直接表达导航状态；视野会按速度和下一转向距离自动缩放。

驾车可选推荐、躲避拥堵、不走高速和少收费策略；高德返回多个有效方案时，配置页会列出最多三条路线的距离与预计时间。偏航确认后显示“重新规划”并限频请求新路线。导航结束会立即隐藏路线；行驶速度较高时，离线场景会更早按当前位置续载，降低驶到数据边缘后出现空白的概率。

配置页提供“路线模拟”测试入口。它只在应用内部沿已缓存的真实路线播放约 60–90 秒，不写入系统模拟位置，因此不会影响高德地图或其他应用。模拟可验证路线进度、下一转向、地图旋转、自动缩放和结束导航；真实 GPS 漂移、实际偏航和弱网仍需道路测试。

非导航状态默认开启“桌面实时跟随”的低功耗模式：不主动启用 GPS，亮屏时使用被动位置与约 30 秒/25 米的网络定位；位置实际移动约 12 米后才刷新地图，不再固定轮询重绘。亮屏时方向传感器会驱动朝向箭头和航向朝上的地图，方向变化约 3° 才更新；熄屏立即注销定位和方向传感器，亮屏再恢复。真实位置离场景中心超过 600 米后才重新读取离线地图。只有正式导航时使用高精度 GPS，位置画面最快约 650ms、航向插值约 200ms 刷新；导航开始时桌面跟随服务暂停，导航结束后恢复。Android 的后台定位限制要求显示一条低优先级常驻通知，可在配置页暂停此功能。
